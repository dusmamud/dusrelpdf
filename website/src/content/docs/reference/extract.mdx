Extract selected pages into a new PDF, in the order you give them.

## Rust

```rust
use dusrelpdf::{extract_pages, extract_pages_range, PageSetOptions};

let pdf = std::fs::read("report.pdf")?;
let opts = PageSetOptions::default();

// Explicit page list:
let out = extract_pages(&pdf, &[1, 2, 3, 5], &opts)?;
let out = extract_pages(&pdf, &[5, 1], &opts)?; // order is yours: 5, then 1

// Range string:
let out = extract_pages_range(&pdf, "1-3,5", &opts)?;
```

Signatures:

- `extract_pages(pdf: &[u8], pages: &[u32], options: &PageSetOptions) -> Result<Vec<u8>>`
- `extract_pages_range(pdf: &[u8], range: &str, options: &PageSetOptions) -> Result<Vec<u8>>`

## JavaScript

```js
import { extractPages, extractPagesRange } from 'dusrelpdf';

const out = extractPages(pdf, [1, 2, 3, 5]);
const out2 = extractPagesRange(pdf, '1-3,5');
```

## Python

```python
from dusrelpdf import extract_pages, extract_pages_range

out = extract_pages(pdf, [1, 2, 3, 5])
out = extract_pages_range(pdf, "1-3,5")
```

## CLI

```bash
dusrelpdf extract report.pdf --pages "1-3,5" -o excerpt.pdf
# Extracted pages 1-3,5 to excerpt.pdf
```

## Range syntax

`"1-3,5"` parses to `[1, 2, 3, 5]` — pages in the order written. The rules:

- **1-based.** Page `0` is an error, never the first page.
- **Duplicates are kept.** `[1, 1]` (or `"1,1"`) copies page 1 twice — the
  extractor clones the page dict so the same page can appear twice.
- **Order is yours.** `[5, 1]` gives a two-page PDF with page 5 first.
- **Reversed ranges are errors.** `"5-2"` → `INVALID_RANGE`.
- **Out-of-range pages are errors** (`PAGE_OUT_OF_RANGE`), never silently
  dropped.

## Errors

| Code | When |
| --- | --- |
| `EMPTY_INPUT` | Empty page list. |
| `INVALID_RANGE` | Malformed range string (empty, `""`, `"1-"`, `"a-b"`…). |
| `PAGE_OUT_OF_RANGE` | A page number is `0` or past the last page. |
| `INVALID_PDF` | The input is not a parseable PDF. |
| `ENCRYPTED_PDF` | The input is encrypted and no (or a wrong) password was given. |
