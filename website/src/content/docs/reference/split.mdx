Split one PDF into several PDFs: one output per range, or one output per
page.

## Rust

```rust
use dusrelpdf::{split_pdf, split_pdf_ranges, split_each_page, PageSetOptions};

let pdf = std::fs::read("report.pdf")?;
let opts = PageSetOptions::default();

// Explicit page lists — one output per list:
let parts = split_pdf(&pdf, &[vec![1, 2, 3], vec![4, 5]], &opts)?;
// parts[0] = pages 1–3, parts[1] = pages 4–5

// Range string — one output per comma-separated item:
let parts = split_pdf_ranges(&pdf, "1-3,4-5", &opts)?;

// One PDF per page:
let pages = split_each_page(&pdf, &opts)?;
// pages.len() == page count; pages[0] is page 1, pages[1] is page 2, …
```

Signatures:

- `split_pdf(pdf: &[u8], ranges: &[Vec<u32>], options: &PageSetOptions) -> Result<Vec<Vec<u8>>>`
- `split_pdf_ranges(pdf: &[u8], ranges: &str, options: &PageSetOptions) -> Result<Vec<Vec<u8>>>`
- `split_each_page(pdf: &[u8], options: &PageSetOptions) -> Result<Vec<Vec<u8>>>`

## JavaScript

```js
import { splitPdf, splitPdfRanges, splitEachPage } from 'dusrelpdf';

const parts = splitPdfRanges(pdf, '1-3,4-5'); // Array<Uint8Array>
const perPage = splitEachPage(pdf);
const explicit = splitPdf(pdf, [[1, 2, 3], [4, 5]]);
```

## Python

```python
from dusrelpdf import split_pdf, split_pdf_ranges, split_each_page

parts = split_pdf_ranges(pdf, "1-3,4-5")   # list[bytes]
per_page = split_each_page(pdf)
```

## CLI

```bash
# One file per range: report-1.pdf (pages 1–3), report-2.pdf (pages 4–5)
dusrelpdf split report.pdf --ranges "1-3,4-5" --out-dir out/

# One file per page: report-1.pdf, report-2.pdf, …
dusrelpdf split report.pdf --each-page --out-dir out/

# Custom prefix instead of the input file's stem:
dusrelpdf split report.pdf --ranges "1-3,4-5" --out-dir out/ --prefix chapter
# → chapter-1.pdf, chapter-2.pdf
```

`--ranges` and `--each-page` are mutually exclusive; one of them is required.

## Range syntax

The range string uses the same syntax as extract (`"1-3,5"`), but grouped
per output file: **each comma-separated item is one output file**, and a
bare number is a one-page file.

| Input | Result |
| --- | --- |
| `"1-3,4-5"` | 2 files: pages 1–3, then pages 4–5 |
| `"1,2,3"` | 3 files, one page each |
| `"1-3,1-3"` | 2 files with the same pages (duplicates allowed) |

Page numbers are 1-based. A reversed range (`"5-2"`), a `0`, a page past
the end, or an empty range is an `INVALID_RANGE` / `PAGE_OUT_OF_RANGE`
error. Note that `split_pdf_ranges` parses `"1-3,4-5"` as two ranges
(`[1,2,3]` and `[4,5]`), while `extract_pages_range` parses the same
string as one flat selection (`[1,2,3,4,5]`) — same syntax, different
grouping. See [Extract](/reference/extract/).

## Errors

| Code | When |
| --- | --- |
| `EMPTY_INPUT` | No ranges given. |
| `INVALID_RANGE` | A range is empty, malformed, or reversed. |
| `PAGE_OUT_OF_RANGE` | A page number is outside `1..=page_count`. |
| `INVALID_PDF` | The input is not a parseable PDF. |
| `ENCRYPTED_PDF` | The input is encrypted and no (or a wrong) password was given. |

<Aside>
  Each output is a standalone PDF containing only its pages, rebuilt from
  the same page objects — content, fonts and images referenced by those
  pages travel with them.
</Aside>
