Five minutes, four jobs. Everything below takes PDF bytes in and returns PDF
bytes out — read a file, call the function, write the result.

## 1. Merge two PDFs

```rust
use dusrelpdf::{merge_pdfs, MergeOptions};

let a = std::fs::read("a.pdf")?;
let b = std::fs::read("b.pdf")?;
let merged = merge_pdfs(&[a, b], &MergeOptions::default())?;
std::fs::write("merged.pdf", merged)?;
// merged.pdf has every page of a.pdf, then every page of b.pdf.
```

```js
import { mergePdfs } from 'dusrelpdf';
import { readFile, writeFile } from 'node:fs/promises';

const merged = mergePdfs([
  new Uint8Array(await readFile('a.pdf')),
  new Uint8Array(await readFile('b.pdf')),
]);
await writeFile('merged.pdf', merged);
```

## 2. Extract pages 1–3 and 5

Page numbers are **1-based**, and ranges use the `"1-3,5"` string form:

```rust
use dusrelpdf::{extract_pages_range, PageSetOptions};

let pdf = std::fs::read("report.pdf")?;
let out = extract_pages_range(&pdf, "1-3,5", &PageSetOptions::default())?;
std::fs::write("excerpt.pdf", out)?;
```

```python
from dusrelpdf import extract_pages_range

pdf = open("report.pdf", "rb").read()
out = extract_pages_range(pdf, "1-3,5")
open("excerpt.pdf", "wb").write(out)
```

Range syntax: `"1-3,5"` means pages 1, 2, 3 and 5, in the order written.
Duplicates are kept (the page is copied once per occurrence). A reversed
range (`"5-2"`), a `0`, or a page past the end of the document is an
`INVALID_RANGE` / `PAGE_OUT_OF_RANGE` error — never a silent skip. See
[Error codes](/guides/error-codes/).

## 3. Watermark every page

```rust
use dusrelpdf::{add_watermark, WatermarkOptions};

let pdf = std::fs::read("draft.pdf")?;
let out = add_watermark(&pdf, &WatermarkOptions {
    text: Some("DRAFT".to_string()),
    ..Default::default() // opacity 0.3, rotation 45°, Helvetica 48pt, centred
})?;
std::fs::write("draft-marked.pdf", out)?;
```

## 4. Number the pages

```rust
use dusrelpdf::{add_page_numbers, PageNumberOptions};

let pdf = std::fs::read("report.pdf")?;
let out = add_page_numbers(&pdf, &PageNumberOptions {
    format: "Page {n} of {total}".to_string(),
    ..Default::default() // bottom-centre, starts at 1, 10pt
})?;
std::fs::write("report-numbered.pdf", out)?;
```

`{n}` is the printed number, `{total}` is the page count. The format must
contain `{n}` — otherwise you get an `INVALID_ARGUMENT` error.

## 5. Same jobs from the CLI

```bash
dusrelpdf merge a.pdf b.pdf -o merged.pdf
dusrelpdf extract report.pdf --pages "1-3,5" -o excerpt.pdf
dusrelpdf watermark draft.pdf --text DRAFT -o draft-marked.pdf
dusrelpdf numbers report.pdf --format "Page {n} of {total}" -o report-numbered.pdf
dusrelpdf info report.pdf
# report.pdf: 12 pages, PDF 1.7, encrypted: false
```

## Errors: what a failure looks like

Functions return a `Result` — bad input is an error, never a panic:

```rust
use dusrelpdf::{extract_pages_range, PageSetOptions};

match extract_pages_range(&pdf, "1-99", &PageSetOptions::default()) {
    Ok(out) => std::fs::write("out.pdf", out)?,
    Err(e) => {
        eprintln!("{}: {}", e.code_str(), e.reason_en);
        // PAGE_OUT_OF_RANGE: Page 99 is out of range (this PDF has 12 pages). ...
        eprintln!("({})", e.reason_hi);
    }
}
```

In JavaScript the same failure is thrown as a JSON string; in Python it is
raised as a `DusrelError`. Same code, same two reasons, every language.
See [Error codes](/guides/error-codes/).
