All notable changes to dusrelpdf. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

Not released yet — work in `main` since 0.1.0, same 0.1.0 core,
nothing published yet.

### Added

- **Phase 2 bindings** — the same core, now reachable from four more
  ecosystems:
  - **Native Node addon** — napi-rs (`crates/dusrelpdf-napi`), lazy-loaded
    with a WASM fallback; the compiled `.node` binary is not committed.
  - **Kotlin + Swift** — UniFFI 0.28.3 bindings
    (`crates/dusrelpdf-uniffi`); the generated sources are committed
    under `bindings/`, and byte-identical regeneration is checked in CI.
  - **Go** — C-API (`crates/dusrelpdf-ffi`, cbindgen header
    `dusrelpdf.h`) with a cgo wrapper module
    `github.com/dusmamud/dusrelpdf-go` (no release/tag yet).
  - **Flutter / Dart** — a Dart package
    (`packages/flutter/dusrelpdf`) using `dart:ffi` over the same shared
    library.

### Fixed

- **CLI rotate** — `rotate --angle -90` now works as well as
  `--angle=-90` (clap `allow_negative_numbers`), with regression tests.
- `packages/LICENSE` is ignored — wasm-pack regenerates it on build.

## [0.1.0] - 2026-11-12

First public release. One package, all 10 operations, one Rust core with
JavaScript/TypeScript, Python and Rust bindings plus a CLI — offline, no
network calls.

### Added

- **Merge** — `merge_pdfs` / `merge_pdfs_default`: join PDFs in order, keep
  the first input's metadata, flat first-page bookmarks per input.
- **Split** — `split_pdf`, `split_pdf_ranges` (`"1-3,4-5"`), `split_each_page`.
- **Extract** — `extract_pages`, `extract_pages_range` (`"1-3,5"`); duplicates
  kept, order preserved.
- **Remove** — `remove_pages`; out-of-range pages are an error, never a
  silent skip; an empty list returns the input unchanged.
- **Reorder** — `reorder_pages`; the order must be a complete permutation.
- **Rotate** — `rotate_pages` with `RotateOptions` (angle must be a multiple
  of 90; negative angles normalised; inherited rotation honoured).
- **Images to PDF** — `images_to_pdf` with `ImagesToPdfOptions`
  (`auto` / `a4` / `letter` / `custom`, `contain` / `fill`); JPEG
  passthrough, transparent PNGs keep alpha via `/SMask`.
- **Watermark** — `add_watermark` (text or image, opacity, rotation, font,
  position, per-page selection).
- **Page numbers** — `add_page_numbers` with `{n}` / `{total}` templates,
  `start_at`, margin and position.
- **Signature** — `place_signature`: handwritten signature image placement
  (transparent PNG recommended; not a digital signature).
- **Info & bulk** — `get_pdf_info` (`page_count`, `version`, `encrypted`,
  `title`, `page_sizes`) and `bulk_extract` (one bad selection never kills
  the batch).
- **Options layer** — `CommonOptions` (password, compress), `MergeOptions`,
  `PageSetOptions`, `WatermarkOptions`, `PageNumberOptions`,
  `RotateOptions`, `ImagesToPdfOptions`, `SignatureOptions`, plus
  `Position`, `BaseFont`, `PageSize`, `ImageFit` enums.
- **Error contract** — 10 stable codes
  (`INVALID_PDF`, `ENCRYPTED_PDF`, `PAGE_OUT_OF_RANGE`, `EMPTY_INPUT`,
  `INVALID_RANGE`, `INVALID_ANGLE`, `INVALID_IMAGE`, `INVALID_ARGUMENT`,
  `INVALID_TYPE`, `OPERATION_FAILED`), each with `reason_en` and
  `reason_hi` (Roman-script Hinglish).
- **CLI** — `dusrelpdf` with `version`, `info`, `merge`, `split`,
  `extract`, `remove`, `reorder`, `rotate`, `images-to-pdf`, `watermark`,
  `numbers`, `sign` and `mock`; global `--json` and `--password`; exit code
  0/1.
- **JavaScript API** — TypeScript wrapper over the WASM core: camelCase
  functions (`mergePdfs`, `extractPagesRange`, `addWatermark`) and
  camelCase option keys, `Uint8Array` in/out, failures thrown as
  `DusrelError` (`.code`, `.reasonEn`, `.reasonHi`), plus Zod schemas
  for the options.
- **Python API** — PyO3 bindings with the same `snake_case` functions as
  the Rust core, dict options with `snake_case` keys (partial dicts
  merge onto the Rust defaults), a `DusrelError` exception
  (`.code`, `.reason_en`, `.reason_hi`), and test-data fixtures
  (`make_test_pdf`, `make_signature_png`, `make_photo_jpeg`).
- **Docs website** — this site: Astro + Starlight, 20+ pages, and an
  in-browser [playground](/playground/) running the real Rust core as WASM.

### Known limitations (v0.1.0)

- No PDF rendering and no tolerant repair of malformed PDFs.
- Merge drops the original outline trees (flat first-page bookmarks
  instead); AcroForm, named destinations and embedded files are not carried
  over.
- Watermark / page-number text is ASCII only (base-14 fonts).
- Signature placement is an image, not a cryptographic digital signature.
- Whole document in memory; no streaming mode.
- Encrypted PDFs need `CommonOptions.password`; only empty-password
  auto-decrypt works without one.

Full list: [Limitations](/reference/limitations/).
